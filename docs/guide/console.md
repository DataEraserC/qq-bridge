# 网页控制台

配置文件里开了 `[console]` 后，浏览器访问 `http://127.0.0.1:3100/?token=<你的令牌>`。
整个管理面都在这一个页面上，**日常配置不需要再碰 TOML**。

## 登录

第一次打开输一次令牌，之后刷新会话还记着（cookie）。令牌只存在你配的 `config.toml`
里，忘了就去看那。

## 四个页签

| 页签 | 干什么 |
|---|---|
| **概览** | 连接在不在线、各会话绑定状态、harness 连接数 |
| **会话** | 每个会话订了哪些房间、水位、与 harness 侧会话的映射 |
| **反馈** | agent 侧报回来的运行反馈（失败原因之类） |
| **配置** | 连接 / 会话 / 人格 / 记忆 / 全局参数的**增删改查** |

## 配置页怎么用

- **新增**：每个区块有「+ 新增」按钮，弹窗里是结构化表单，不是裸文本框；
- **编辑**：每条记录有「编辑」按钮；
- **删除**：每条记录有「删除」，会弹确认；
- **保存即热重载**：写回 TOML 用的是外科手术式补丁——你的注释、排版、没碰的键全部原样保留；
- **兜底**：右上角有「编辑 TOML」直接改原文，改完一样热重载。

删掉的东西如果还有别人引用它（比如删了人格还有会话挂着它），保存时会整体校验并报错，不会写出坏配置。

## 重置会话（断开映射）

「会话」页签里每个会话有 **「断开映射并重置」**。它干的事：

1. 解开桥侧会话与 harness 侧（如 dsh 里那个会话）的绑定；
2. 下一轮对话时，驱动会拿新 id 重新建一个 harness 侧会话——上下文清零，从头开始。

什么时候用：agent 被长对话带偏了、harness 侧会话坏了报错、或者想让 dsh 里的会话
换个工作区/重新归组。

## 安全说明

- 控制台所有请求都校验令牌（Bearer 头或 `?token=`），令牌比较是常量时间比较；
- 默认只听 `127.0.0.1`，要远程访问就改 `listen = "0.0.0.0:3100"` 并**务必**换强令牌，
  再考虑上反代加 TLS；
- 响应带全套安全头（CSP / XFO 等），页面无外部依赖，不加载任何第三方资源。
