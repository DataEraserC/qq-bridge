# 架构文档

本目录定义 QSH 的分层、领域模型、协议与不变量。**它描述将要建成的系统**——仓库当前没有代码，旧实现已整体删除。

## 阅读顺序

| 顺序 | 文档 | 回答什么问题 |
| --- | --- | --- |
| 1 | [总览](01-overview.md) | 系统由几个进程组成，边界画在哪 |
| 2 | [领域模型](02-domain-model.md) | 账号、人格、设备、范围、记忆分别是什么，怎么配置 |
| 3 | [内核](03-kernel.md) | QQ 侧要做哪些事，按什么顺序 |
| 4 | [适配器](04-adapter.md) | agent 运行时侧要做哪些事，怎么保持中立 |
| 5 | [协议](05-protocol.md) | 两个进程之间说什么话 |
| 6 | [钩子](06-hooks.md) | 用户脚本能挂在哪些位置，能改什么 |
| 7 | [不变量](07-invariants.md) | 哪些行为不可配置、不可绕过 |

先读 1 和 2 就能理解设计意图；3 到 5 是实现者的必读；6 面向写规则的人；7 是所有改动的检查单。

## 与其它目录的关系

- 术语定义在根目录 [GLOSSARY.md](../../GLOSSARY.md)。本文档不使用术语表之外的词指代同一概念。
- 决策与理由在 [docs/adr/](../adr/README.md)。本文档只描述**是什么**，不论证**为什么**。
- 使用方法在 [docs/manual/](../manual/README.md)。本文档不写操作步骤。
