# ADR-0008 harness 接入：接入点 + 回合票

来源：实现默认（沿用旧实现验证过的机制），可以随时推翻。

## 这条决定了什么行为

- harness 通过**接入点**连进桥：本机套接字或 TCP，TCP 时必须配接入令牌。
- 协议是双向帧流：harness 收投递（未读、上下文），发回合开始/结束、工具调用；桥回工具结果、日志。
- 一个设备绑定一个记忆名（harness 侧的会话标识）。桥不关心 harness 内部是什么、用哪个模型——换 harness 只换配置。
- 回合票在开轮次时签发，是工具身份的唯一来源；收工即作废。

## 不这样会怎样

如果桥自己去实现 agent：等于把 DSH/WorkBuddy/Trae 的活重干一遍，而且每接一个新 harness 就要重干一遍。如果不验票：迟到或伪造的调用会把消息发进错误的对话。

## 技术细节

帧定义放独立的 `proto` crate，harness 侧接入库可直接复用。帧格式带版本号，向前兼容靠新增变体、不改旧字段。
