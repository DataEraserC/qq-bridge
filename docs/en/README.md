## Rules for translators

- One English file per Chinese file, same filename.
- Translate the prose, not the identifiers. `memory`, `scope`, `device`, `account`, `persona`, `hook`, `turn ticket` are the canonical English terms — see [GLOSSARY.md](../../GLOSSARY.md).
- Code blocks, config keys, and Mermaid diagrams are copied verbatim.
- When a Chinese file changes, the English file is stale until updated. Note it rather than leaving a silent mismatch.
